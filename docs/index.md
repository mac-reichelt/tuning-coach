# Tuning Coach Documentation

Welcome to Tuning Coach! This project overlays real-time telemetry and tuning recommendations on Forza Motorsport and Horizon. Now includes a guided Dyno panel and Raw Telemetry viewer.

## Features
- Real-time telemetry HUD
- Guided Dyno panel (power/torque curves)
- Raw Telemetry panel
- Lap validity badge
- Tuning recommendations

## Getting Started
- [Quickstart](getting-started.md)
- [API Reference](reference/api.md)
- [Lap Validity](reference/lap-validity.md)

## Overlay Panels

### Dyno Panel
- Collect power/torque curves in-session
- Step-by-step instructions
- Drag to reposition

### Raw Telemetry Panel
- Inspect all Forza packet fields
- Drag to reposition
