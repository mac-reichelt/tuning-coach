# overlay

SimHub overlay for `tuning-coach`. Vanilla HTML/CSS/JS — no build step.

The overlay connects to the sidecar over a localhost WebSocket and renders a
minimal "quiet" HUD that surfaces only when the coach has a recommendation.

## Install

Copy or symlink this directory into your SimHub `DashTemplates` folder, then
enable the overlay from SimHub's overlay manager.
