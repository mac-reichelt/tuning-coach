# Contributing

Thank you for your interest in contributing! This project uses agent-driven review workflows to ensure quality and correctness. Please review the full contributing guide at [docs/contributing.md](docs/contributing.md) for:

- Agent routing matrix: which agent files to consult for different code paths
- Automated review workflows: how CI checks enforce agent conventions
- PR description requirements: how to document consulted agents and test coverage
- Procedural steps for submitting a PR

**Summary:**
- Consult agent files as required by the routing matrix before making changes
- Add or update tests for new public functions or modules
- Fill out the PR template and note consulted agents
- Address agent review feedback if any checks request changes

See [docs/contributing.md](docs/contributing.md) for full details.
